# ずんだもん解説動画スタジオ

台本を書いたJSONを1つ渡すと、**動画・サムネイル3案・タイトル候補・概要欄**を
まとめて書き出します。VOICEVOXの取得と起動も自動です。

```bash
python3 studio.py 台本.json
```

出力は `out/` に入ります。

| ファイル | 中身 |
|---|---|
| `video.mp4` | 1080p・立ち絵と背景つきの本編。母音に合わせた口パクつき |
| `thumbnail_alert / _guide / _number .jpg` | サムネイル3案(1280×720)。背景は出来上がった動画のフレームから作るので、動画と見た目が揃う |
| `thumbnail_smallcheck.png` | スマホ最小表示168×94での見え方 |
| `description.txt` | 概要欄。そのまま貼り付け可 |
| `title_description.md` | タイトル候補・字数チェック・概要欄 |

所要時間の目安は、初回が**約15分**(VOICEVOXの取得45秒＋音声合成9分＋書き出し5分)、
2回目以降は音声がキャッシュされるので**約5分**です。台本の一部だけ直した場合、
変更した文だけ再合成されます。

## 手作業が残るところ

**YouTubeへの投稿だけは自動化できません。** この作業環境から `googleapis.com` へ
接続できず、OAuthの段階で止まるためです。書き出した `out/` の中身を、
ご自身でアップロードしてください。

台本そのものを書くのもClaude側の仕事です。テーマを決めて相談してもらえれば、
下の形式のJSONを作ります。

## 台本JSONの書き方

```jsonc
{
  "chapter": "画面上部に出る章名",

  "scenes": [
    {
      "title":   "スライドの見出し",
      "expression": "normal | happy | surprise | think",
      "keywords": ["テロップで色を変えたい語"],
      "bullets": ["箇条書き", "3つくらいが目安"],
      "narration": "読み上げる文。。で区切った文ごとにテロップが出ます。"
    }
  ],

  "thumbnail": {
    "from_scene": 7,          // サムネの背景に使う動画のシーン番号(省略時は1)
    "eyebrow": "肩に置く小さいラベル",
    "alert":  { "expr":"surprise", "l1":"上の行", "hero":"一番大きい語",
                "l3":"下の行", "sub":"最下部の補足" },
    "guide":  { "expr":"normal", "badge":"左上のバッジ", "l1":"", "hero":"", "l3":"", "sub":"" },
    "number": { "expr":"think", "l1":"上の行", "num":"3", "l2":"つの", "l3":"", "sub":"" }
  },

  "meta": {
    "titles":   ["タイトル候補(30字以内)", "..."],
    "hook":     "概要欄の冒頭3行。もっと見るの前に出る部分",
    "body":     "本文。300字前後が目安",
    "terms":    [["用語", "説明"]],
    "credits":  ["立ち絵:配布元"],
    "hashtags": ["3〜5個"]
  }
}
```

### 決まりごと

- **数字は漢数字で書いてください。** 画面には自動で算用数字(100株・3つ)に
  変換されますが、読み上げ側は漢数字のほうが正しく発音されます。
- **目次のタイムスタンプは自動計算**されます。書く必要はありません。
- **`VOICEVOX:ずんだもん` のクレジットは自動で入ります。**
  利用規約上の必須項目なので、消さないでください。
- 表情は4種類、口は母音ごとに5種類+閉じ口の計6種類です。
  `assets/frames/` に `表情名_母音.png`(母音は a i u e o x)を置きます。
  xが閉じ口です。VOICEVOXが返すモーラの母音に合わせて自動で切り替わります。
  素材はPSDのレイヤーから書き出しています(製作:坂本アヒルさん)。

## 中身

```
studio.py              入口。これだけ実行すればいい
lib/setup.py           VOICEVOXの取得・起動、不足パッケージの導入
lib/video.py           スライド描画・音声合成・テロップ・動画組み立て
lib/thumbnail.py       サムネイル3案
lib/metadata.py        タイトル字数チェックと概要欄
assets/frames/         立ち絵(表情4種×揺れ2枚)
.cache/                音声キャッシュと作業用。消しても動きます
```

## サムネイルとタイトルの根拠

調べた定石に合わせてあります。メイン文字80〜120px、袋文字は文字サイズの5〜10%、
文字数は6〜15字、顔は画面の1/3以上、白・黒・黄が万能色、教育系は青・注意喚起は赤。
タイトルは30字以内で検索語を前半へ。概要欄は冒頭1〜2行にキーワード、本文300字前後、
チャプターは0:00から、ハッシュタグは3〜5個。
`title_description.md` に字数の判定が出るので、超えていればそこで分かります。
